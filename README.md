# ***GERMAN***
Ein Script zum Erstellen von Sperrzonen (nur mit Job, zbsp. Polizei). 

# 🔧 Features

- Simples Menu (per ox_lib)
- NPC Verkehrssteuerung (Geschwindigkeit für NPCs anpassen)
- Blip Radius (Zone) auf Map erstellen
- Automatisches entfernen nach Zeitablauf
- Jobbasierter Zugriff
- Notify Kompatibilität (ESX, GTA Native, Bulletin, OX oder ein eigenes selber hinzufügen)

# 🚀 Installation

1. Lege den Ordner `RCRP-restrictedzone` in deinen `resources/` Ordner.
2. Füge folgendes in deine `server.cfg`:
 `            ensure RCRP-restrictedzone            `
3. Richte das Script in der Config so ein, wie es für dich passt.


# ***ENGLISH***
A script for creating restricted zones (only available with a job, e.g., police). 

# 🔧 Features

- Simple menu (via ox_lib)
- NPC traffic control (adjust NPC speed)
- Create blip radius (zone) on map
- Automatic removal after a set time
- Job-based access
- Notification compatibility (ESX, GTA Native, Bulletin, OX, or add your own)

# 🚀 Installation

1. Place the `RCRP-restrictedzone` folder in your `resources/` folder.
2. Add the following to your `server.cfg`:
 `            ensure RCRP-restrictedzone            `
3. Configure the script in the config file to suit your needs.

# DEPENDENCY
- ox_lib (https://github.com/overextended/ox_lib/releases)
